# 1. Modèle sudoAMM

sudoAMM transforme un NFT en actif échangeable contre un token dans une pool. Chaque pool encode une courbe de prix et les paramètres de frais.

Ce chapitre relie le mécanisme aux contrats concernés et explicite les invariants utiles à un intégrateur.
